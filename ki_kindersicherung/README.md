# KI-Kindersicherung

AppDaemon-Anwendung für Home Assistant mit Medienpause, Sprachaufgaben und dem Wissensquiz Klugscheißer. Das Paket enthält den App-Code, Home-Assistant-Skripte und Sprachsätze, ein Verwaltungsdashboard und einen PowerShell-Installer.

Die Installation erfolgt in einer vorhandenen AppDaemon-Instanz. Details zur Einrichtung und Wiederherstellung stehen in [DOCS.md](DOCS.md).
