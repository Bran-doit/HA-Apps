# Lizenzstatus

Für die neu erstellten Dateien dieses Entwicklungsexports ist noch keine eigenständige Open-Source-Lizenz festgelegt. Die öffentliche Bereitstellung allein erteilt keine darüber hinausgehenden Nutzungsrechte. Vor einer regulären Softwarefreigabe ist die Lizenz durch den Rechteinhaber festzulegen.

Die separaten Drittanbieter-Komponenten unterliegen ausschließlich ihren eigenen Lizenzen; siehe THIRD_PARTY_NOTICES.md. Deren Code wird hier nicht mitgeliefert.
